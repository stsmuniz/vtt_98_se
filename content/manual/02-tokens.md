Um **token** é um modelo reutilizável que representa um personagem, um monstro, um objeto ou qualquer elemento que possa ser posicionado sobre uma cena.

## Cadastrando um token

Abra **Dashboard → Token** (ícone de tokens) para ver a lista de tokens já cadastrados e criar novos. Ao inserir ou editar um token, você pode definir:

- **Imagem** — a arte que representa o token no mapa.
- **Nome** — usado para identificá-lo nas listagens e, nas salas, para diferenciar cópias do mesmo token (veja a seção sobre Salas).
- **Tamanho** — largura e altura padrão ao ser colocado em uma cena.
- **Atributos** — pares de informação livre (por exemplo "Vida", "Mana" ou "Sanidade") que ficam associados ao token.
- **Tags** — palavras-chave para facilitar a busca e organização.

É preciso preencher pelo menos uma imagem e o nome para cadastrar um token. As outras propriedades são opcionais.

## Usando um token em uma cena ou sala

Um token cadastrado é apenas um modelo. Ao **adicionar um token a uma cena** (ou a uma sala) uma cópia independente dele é criada — chamada de instância — que pode ser movida, redimensionada, girada e ter seus atributos ajustados sem alterar o token original. Isso significa que você pode reaproveitar o mesmo token cadastrado em várias cenas diferentes, cada uma com sua própria posição e configuração.
