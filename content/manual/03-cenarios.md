Um **cenário** é a imagem de fundo (o mapa) sobre a qual os tokens de uma cena são posicionados — uma masmorra, uma cidade, uma floresta, um mapa de mundo, etc.

## Cadastrando um cenário

Abra **Dashboard → Cenário** para ver a lista de cenários cadastrados e criar novos. Ao inserir ou editar um cenário você define:

- **Imagem** — o mapa em si.
- **Nome** — para identificá-lo nas listagens.
- **Tags** — palavras-chave para facilitar a busca.

Assim como acontece com os tokens, o mesmo cenário pode ser reaproveitado por diversas cenas diferentes: ele é apenas a base visual, enquanto cada cena guarda sua própria disposição de tokens sobre aquele mapa.
