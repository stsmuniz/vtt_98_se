## Rolador de dados

O ícone **Dados** (disponível no Dashboard e nas salas) abre uma janela flutuante com o rolador de dados, útil para testes rápidos sem sair da sessão.

Na janela é possível configurar:

- **Qtde** e **Faces** — quantos dados rolar e de qual tipo (d4, d6, d8, d10, d12 ou d20).
- **Mod** — um modificador numérico, positivo ou negativo, somado ao resultado final.
- **Rolagem** — como o resultado final é calculado: **Soma** (todos os dados somados), **Maior** (o maior valor entre os dados rolados) ou **Menor** (o menor valor entre os dados rolados).

### Rolando mais de um tipo de dado na mesma rolagem

Para combinar dados diferentes em uma única rolagem (por exemplo, 2d6 junto com 1d8), configure a Qtde/Faces desejada e clique em **Adicionar dado** — o dado é incluído em uma lista logo abaixo, onde também é possível removê-lo individualmente. Repita para cada tipo de dado que fizer parte da rolagem.

Enquanto essa lista estiver vazia, o botão **Rolar** usa apenas a configuração de Qtde/Faces visível na tela, como sempre funcionou. A partir do momento em que pelo menos um dado é adicionado à lista, **Rolar** passa a considerar somente os dados da lista (ignorando a Qtde/Faces ainda exibida nos campos) — o modificador e o tipo de rolagem continuam se aplicando ao resultado combinado.

## Iniciativa

Dentro de uma sala, o ícone **Iniciativa** abre uma janela flutuante que lista automaticamente todos os tokens presentes na sala, permitindo registrar o valor de iniciativa de cada um e organizar a ordem de turnos do combate. A lista se mantém sincronizada com os tokens da sala: ao adicionar ou remover um token, a lista de iniciativa é atualizada de acordo.
