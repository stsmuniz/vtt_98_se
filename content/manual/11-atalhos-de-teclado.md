Os atalhos de uma janela só funcionam enquanto ela está **ativa** (com a barra de título destacada). Os atalhos de sistema funcionam sempre.

## Em qualquer lugar

| Atalho | O que faz |
| --- | --- |
| **F1** | Abre este manual. |
| **Alt+I** ou **Ctrl+Esc** | Abre ou fecha o menu **Iniciar**. |
| **Alt+W** | Alterna entre as janelas abertas; **Shift+Alt+W** volta. Solte o Alt para escolher. |
| **Esc** | Fecha menus e caixas de mensagem. |

Quando a janela ativa tem um menu com a letra **I** (como **Inserir** no editor), **Alt+I** abre esse menu em vez do Iniciar. Nesse caso, use **Ctrl+Esc** para o Iniciar. Em alguns sistemas operacionais o **Ctrl+Esc** é reservado pelo sistema.

## Menus

Cada menu tem uma letra sublinhada. Pressione **Alt** e a letra para abri-lo — por exemplo, **Alt+A** para **Arquivo** — e depois a letra do item. As setas navegam e **Enter** escolhe.

## Nas pastas

| Atalho | O que faz |
| --- | --- |
| **F2** | Renomear o item selecionado. |
| **Delete** | Excluir o item selecionado, com confirmação. |
| **Alt+Enter** | Propriedades do item. |
| **F5** | Atualizar a lista. |

## Em formulários

| Atalho | O que faz |
| --- | --- |
| **Ctrl+S** | Gravar (equivale a **OK**). |
| **Enter** nas tags | Adicionar a tag digitada. |

## No editor de cenas e na sala

| Atalho | O que faz |
| --- | --- |
| **Ctrl+S** | Salvar a cena (ou a sala, para o mestre). |
| **Delete** | Remover o token selecionado, depois de confirmar. |
| **Ctrl + roda do mouse** | Zoom no mapa. |

## No manual

| Atalho | O que faz |
| --- | --- |
| **Alt+Esquerda** | Voltar ao tópico anterior. |
| **Alt+Direita** | Avançar. |
| **Ctrl+P** | Imprimir o tópico. |
