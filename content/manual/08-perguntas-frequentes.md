**Preciso de uma conta para jogar em uma sala?**
Não. Apenas o mestre (dono da sala) precisa de uma conta para cadastrar tokens, cenários, cenas e criar a sala. Jogadores entram direto pelo link da sala, informando a senha quando houver uma.

**Minhas edições em uma cena ou sala são salvas automaticamente?**
Não. Use sempre o ícone (ou o atalho de menu) **Salvar** para gravar as alterações. Em salas, o único caso de sincronização automática é a transmissão ao vivo dos movimentos de token para os visitantes — o que é diferente de persistir a alteração no banco de dados.

**Posso usar o mesmo token em várias cenas ou salas?**
Sim. Um token cadastrado é um modelo reutilizável; cada cena ou sala guarda sua própria cópia independente (instância) dele, com posição, tamanho e atributos próprios.

**Como eu convido meu grupo para uma sessão?**
Compartilhe o link da sala (`/rooms/<código>`), disponível na listagem de salas. Se a sala tiver senha, avise seu grupo dela.

**O que acontece se eu fechar a sala?**
Fechar a sala impede que novos visitantes entrem; quem já estava dentro continua participando normalmente. Reabra a sala a qualquer momento pelo mesmo botão.
